### 小结

过去 5 个季度，收入增速（CN）分别为 -1% / 0% / -3% / -4% / -5%，趋势在恶化而非改善。但这主要由 Greater China（-10% → -26%）、Sportswear/Jordan 主动减量、以及 Converse reset 驱动——Performance 组合实际上在高单位数增长，北美连续 5 季正增长。OPM 剔除一次性项后在 3-8% 区间波动，underlying 利润率水平显著低于 FY2024 的 12.3%。

当前 Forward PE 27.1x、Forward NPM ~4.4% [Valuation Screening 2026-10-12]。Forward NPM 从上次扫描的 5.5% 进一步下降至 4.4%，正在向困境反转门槛（~3%）靠拢但尚未触及。FY27E EPS 一致预期被砍 23% 至 $1.28，FY27E 收入预期 $42.9B（-7.5%），意味着市场预期 FY27 全年盈利能力将显著低于 FY26。

两个新季度的最大增量信息：（1）**Pace 计划**——$2.5B 节省目标是管理层首次给出的具体利润率修复路径，但主要兑现在 FY29-30，短期还是成本期；（2）**Greater China 加速恶化**——数字渠道全面清理、CFO 明确 FY27 剩余时间将进一步恶化，这个地区的底部可能在 FY28 才出现；（3）**新 CFO Dave Denton**——引导风格更加透明和保守，FY27 adj EPS 指引 $1.15-$1.35，11 月 Investor Day 将公布长期增长算法。

## 二、投资机会判断

NKE 仍然是一个"龙一在周期底部做正确的事"的状态，方向正确但赔率有限。过去两个季度，这个判断的两侧同时在演变：一方面基本面在"变得更差"——收入增速从 -1% 恶化到 -5%（CN），Forward NPM 从 5.5% 降至 4.4%，Greater China 从 -10% 恶化到 -26%，FY27E EPS 被砍 23%——这意味着 NKE 正在向我们框架中"够差"的方向移动。另一方面，"在变好"的证据也在积累——Performance 组合持续高单位数增长证明 sport offense 是有效的，Pace 计划首次量化了利润率修复路径（$2.5B），北美 wholesale 连续正增长且与 Foot Locker 4 年来首次双正增长。

问题在于这两个方向目前无法对冲。NKE Forward NPM 4.4% 虽在下降但仍远高于困境反转门槛的 ~3%，Forward PS 1.20x 更是远高于底部公司的 0.2-0.5x 区间。而"在变好"的部分——Performance 增长强劲——已经被市场定价（27x PE 不低）。换言之，NKE 处在一个尴尬的中间地带：利润率不够低以至于有大的修复弹性，但估值也不够便宜以至于有安全边际。

与上次扫描相比，我们认为 set-up 有微妙的边际改善：Forward NPM 下降使其更接近"够差"门槛，Pace 计划提供了此前没有的利润率修复 visibility，而股价基本没动（-3%），潜在的 risk-reward 在改善。但这还不足以改变机会大小的判断——NKE 需要 Forward NPM 进一步下降到 3% 附近，或者 Sportswear/Jordan 出现明确的收入拐点，才能构成一个有赔率的反转机会。

如果未来 12 个月观察到以下信号，需要重新评估：（1）Sportswear 从双位数下滑收窄到低单位数或持平——意味着 classics reset 完成、新品开始 scale；（2）Greater China 季度收入降幅收窄至 -10% 以内——意味着数字渠道清理告一段落；（3）Forward NPM 降至 3% 以下——可能因 Pace 实施成本叠加持续的 Sportswear/Jordan 拖累，会触发困境反转门槛。11 月 Investor Day 是关键催化剂——如果管理层给出清晰的中期利润率回归路径（双位数 EBIT margin timeline），市场可能重新定价。

### 论断追踪（vs 上次扫描 2026-09-25）

1. **Running 20%+ 增长是 sport offense 有效性的核心证据** → **维持**
   连续 5+ 季双位数增长，世界杯和产品矩阵扩展（Alphafly 4、Swooshfly、NIKE Apex）继续驱动。已从早期信号变为 established fact。

2. **Greater China 持续恶化，需要全面重置** → **强化**
   从 -10%（Q3）加速恶化到 -17%（Q4）、-26%（Q1）。启动数字渠道全面清理（取消不符策略的分销、减少深折），CFO 明确 FY27 剩余时间将进一步恶化。底部可能在 FY28。

3. **经典鞋款从峰值削减 $4B 是短期压力但改善 marketplace 健康度** → **强化**
   Dunk 在 FY27Q1 进一步减量~50%，Jordan Retro 将刻意减少频次和量。管理层开始将 Sportswear 拆分为更小聚焦领域——从管理 classics 转向建立新品梯队。AF1 已稳定全价，P-6000/V5 Runner 强双位数增长是早期正面信号。

4. **关税年化 $1.5B 是 GM 的主要结构性压力** → **减弱**
   FY26Q4 确认 $986M IEEPA 关税退还。供应链结构性降本已在 FY27Q1 贡献 +90bps。但关税仍是动态逆风，IEEPA 10% → 15% 预期，净影响难以量化。不再是最大矛盾。

5. **以 21x PE 和 5.5% 净利率来看，市场已 price in 恢复预期** → **减弱**
   FY27E EPS 从 $1.66 砍至 $1.28（-23%），市场并未 price in 恢复——反而在大幅下修盈利预期。但股价仅跌 3% 而 PE 升至 27x，说明市场给长期修复留了信用，估值并未因 earnings 下修而变便宜。

6. **NKE 不满足困境反转的"够差"门槛（Forward NPM 5.5%，OPM 7-8%）** → **维持，但在靠近**
   Forward NPM 从 5.5% 降至 4.4%，underlying OPM 在 3-8% 区间波动（Q4 剔除后仅 3.1%）。距离困境反转的 ~3% NPM 门槛更近了，但尚未触及。PS 1.20x 仍远高于底部公司 0.2-0.5x。

**新增变量：**
- **Pace 计划 $2.5B 节省**——首次给出具体利润率修复路径。但兑现主要在 FY29-30，实施成本 $1B + FY26 已确认 $300M 裁员费。短期是成本不是收益。
- **新 CFO Dave Denton**——引导风格比 Matt Friend 更保守透明。FY27 adj EPS 指引 $1.15-$1.35。将组织架构从 4 个地理区整合为 3 个（Americas / APGC / EMEA），FY28 生效。
- **Investor Day 11 月 16-17 日**——将公布长期增长算法和投资优先级，是近期最重要催化剂。
- **FY27Q1 首次量化 Performance vs Sportswear vs Jordan**——Performance 占 ~38-40%（高单位数增长）、Sportswear 占 ~47-49%（低双位数下滑）、Jordan 占 13%（中双位数下滑）。两个下滑组合占约 60%，拖累大于增长组合的拉动。

**机会大小：—（vs 上次 —）**。Forward NPM 4.4% 仍高于困境反转门槛 ~3%，Forward PS 1.20x 远高于底部公司 0.2-0.5x。龙头底部利润率弹性受限——即使回到双位数 EBIT margin，是回归常态而非超额修复，且时间在 FY29-30。27x Forward PE 已给了不少长期修复的信用。

**变化：机会边际改善，但尚不构成升级**。Forward NPM 从 5.5% 降至 4.4%（-1.1ppt），正在向"够差"门槛靠拢。Pace 计划提供了此前没有的利润率修复 visibility。如果 FY27 后续几个季度 NPM 进一步下降至 ~3%，且 Sportswear/Jordan 出现收入拐点，NKE 可能从"—"升级为"小"。Investor Day（11 月）是关键观察节点。
