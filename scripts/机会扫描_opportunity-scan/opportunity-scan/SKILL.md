# 机会扫描

目的：防止因为精力有限而漏掉机会。对股票池里的每家公司，先把基本面整理成统一格式，再判断它现在的 set-up 是不是历史上某类大机会的起点、机会有多大。

**大部分公司的 set-up 都一般。** 判断的默认结论是"set-up 一般"；只有过了类型门槛，才去匹配历史案例、给机会大小。不要为了给出类比而硬凑。

## 输入、数据来源与输出位置

- **输入**：一个或多个 ticker，或用户的股票池文件。
- **财务与业务拆分**：优先用研究系统里的 filings（10-K、10-Q、年报、中报、业绩公告）；年度和季度的收入、毛利率、OPM、净利率也可以用 FMP 利润表核对。
- **一致预期与估值**：估值 snapshot 或 FMP（Forward PE、Forward PS、Forward 净利率）。
- **业绩会 transcript**：研究系统里的 transcript；拿不到就标"缺失"，不得凭印象补写。
- **输出位置**：Obsidian vault 路径以工作目录 `CLAUDE.md` 中写明的为准；没写就问用户一次。笔记放在 `<vault>/机会扫描/`，每家公司一个 `<TICKER>.md`，外加 `summary.md`。

## 每家公司的流程

每份笔记分两部分：**一、基本面**（第 1–2 步），**二、投资机会判断**（第 3–6 步）。第 7 步写入 Obsidian，第 8 步填写公司跟踪表。

### 第 1 步：整理基本面数据（第一部分的表格）

按 `output-template.md` 的字段整理，缺什么标缺失：

1. **年度财务**：过去 3 个财年的收入、收入同比、毛利率、净利率。
2. **季度财务**：过去 3 个季度的收入、收入同比、毛利率、OPM、净利率。
3. **业务拆分**：公司口径，过去 3 个季度，一到两层。第一层按公司主要披露维度（分地区，或批发/直营），第二层在其下细分（例如分地区后再分渠道，中国再分线上/线下）。只用公司披露的拆分。
4. **关键经营数据**：门店数、店效、同店、ASP/AUR、折扣率、库存等，公司披露什么写什么。
5. **当前估值**：Forward PE、Forward PS、Forward 净利率。
6. **最近 3 个季度的业绩会 transcript**：提取最新一季的主要关注点（分析师问得最多、管理层着重解释的 2–3 个问题），以及每季在管理层、战略、产品、客群、渠道五项上发生了什么。

### 第 2 步：写基本面小结（第一部分末尾）

一段话，固定顺序：

> 过去 3 个季度，收入增速分别为 [a / b / c]，OPM 分别为 [a / b / c]；当前 Forward PE / PS 分别为 [x / y]，Forward 净利率约 [z]；最近几个季度财报的主要关注点在 [……]（根据最新业绩会 transcript）。

### 第 3 步：门槛判断——有没有 set-up

读 `opportunity-types.md`，看是否满足至少一类的门槛：

| 类型 | 门槛（同时满足） |
|---|---|
| 困境反转 | 利润率足够低（Forward 净利率约 3% 以下，或 OPM 低个位数）；估值在自身历史低位（PS 约 10 年低分位）；收入较峰值有明显回撤；transcript 中有实质性的变化动作（换管理层、战略重置、砍 SKU、关店等） |
| 公司成长·低基数非线性 | 单一品牌收入约 20 亿美元以下；增长强或在加速；有品牌热度或产品辨识度的证据；渠道还没充分放量 |
| 公司成长·品牌升级 | 明确的升级动作（砍低端批发、加直营、门店升级、提价），且 AUR 上升或折扣下降已在数字上出现 |
| 公司成长·国牌改革（品牌周期） | 行业需求上行 + 公司自身品牌势能起来（热度、提价、核心产品线高增长） |
| 公司成长·全球化故事 | 海外渗透率明显低于同行，且海外增长或海外利润率开始兑现 |
| 行业需求驱动 | 能指认一轮正在发生或刚开始的行业/赛道 Beta（参照 `data/beta_periods.csv` 的几轮），且公司是明显受益者 |

**都不满足**：`size` 记为"—"，`type` 为空，不跑匹配、不写类比；结论段写"set-up 一般"（格式见 `output-template.md` 第 3 节），直接写第 6 步的五维度表。

### 第 4 步：确定类型并匹配历史案例

**4a. 定量匹配。** 在 skill 根目录运行：

```bash
python scripts/match_setup.py --npm <Forward净利率> --ps <Forward PS> --pe <Forward PE> \
    [--ps-pct <PS分位> --rev-vs-peak <收入距峰值> --rev-g12 <收入预期12M变化> --npm-chg12 <净利率12M变化> --rev <收入亿美元>] \
    [--type 困境反转|自身成长|行业Beta]
# 公司在历史面板里时也可以用：--company <代码> --month <YYYY-MM> --exclude-self
```

脚本返回指纹最接近的历史起点及其之后的路径。距离 d > 0.8 会标"不够相似"；最近的都不够相似时，就是没有合适的定量类比。

**4b. 定性确认。** 对候选案例，读 `data/cases.json` 的人事/产品/品牌/渠道/行业Beta/评论字段和 `case-library.md` 的案例卡片，比较**起点 set-up**：利润率与估值水平、收入趋势、五项变化、Beta 环境、体量与业务模式。

定量最像和定性最像不一致时，以定性为准。定量和定性都找不到足够像的案例时，`analog` 留空，结论段不写"和…很像"，只写类型。

### 第 5 步：判断机会大小（大 / 中 / 小）

机会大小是定性判断，不做赔率测算。核心是两件事：**起点够不够差、够不够便宜**（决定空间），以及**变化有多确定**（是否已经在变好、证据有多硬）。有行业或赛道 Beta 支撑的，同等条件下往上调一档。

| 类型 | 大 | 中 | 小 |
|---|---|---|---|
| 困境反转 | 足够差 + 在变好：利润率极低、估值在历史底部，且五项变化是系统性的（多项同向），财务上已出现早期信号（毛利率同比改善、收入降幅收窄或加速） | 足够差、变化已启动但数字上还没体现；或已在变好但利润率只是中低个位数，弹性有限 | 不够差：即使处在下行周期，利润率仍不低（例如龙头公司周期底部 OPM 仍在高个位数以上），修复空间有限；或足够差但看不到明显改善迹象（只有换 CEO 或口号） |
| 公司成长（四个子类） | 变化确定且还没被估值充分反映：如低基数单品牌、产品有辨识度、热度高于收入、渠道刚开始扩张；或升级动作系统、AUR 与折扣已在数字上改善、收入拐点临近，而估值仍在行业中低位 | 变化确定但估值已部分反映；或变化在进行但数字尚未验证 | 增速在放缓、单一品牌体量接近天花板（约 50 亿美元），或估值已很高、需要更高增速才能消化 |
| 行业需求驱动 | 新一轮 Beta 的起点（预期极度悲观后的拐点，或结构性变化刚开始），且公司弹性大（利润率低、估值低） | Beta 已在进行，公司受益但弹性一般 | Beta 后期，或公司受益有限 |

`size_reason` 用一到两句话写清楚依据，例如"足够差（Forward 净利率约 2%、PS 处于 10 年低位），但最近 3 个季度只有换 CEO，产品和渠道尚无动作，看不到在变好，记为小"。

### 第 6 步：写"投资机会判断"

**结论段**（有 set-up 时）：

> 目前 [公司] 的 set-up 是"[类型候选]、[所处阶段]"：最近 3 个季度，[管理层、战略、产品、客群、渠道中最重要的 1–3 个变化]。如果未来 [可观测的触发条件]，和 [时间段] 的 [历史公司] 很像（[类比案例的兑现路径，如净利率 x → y、PS x → y]），是一个"[大类，子类型]"的机会。

- "如果未来"必须可观测、可跟踪，带指标和方向，例如"毛利率同比改善 1–2 个点，且收入增速较上季明显加速""门店数从净关闭转为企稳""北美批发渠道结束清理、恢复增长"。不要写"基本面改善""执行到位"。
- 兑现路径取自类比案例的实际数字（`cases.json` 的 before/after 或脚本输出），只作参照。
- 同时命中多个类型时，可以写"更像 A（理由），也有 B 的成分"。

**类型标注**一律写成"大类，子类型"：

| 大类 | 子类型 |
|---|---|
| 行业需求驱动 | 行业整体需求 Beta；结构性 Beta（如 value brand、"大哥倒了，小弟吃饱"）；赛道 Beta + 龙一 |
| 困境反转（原文称底部反转） | 按品牌举措：代言联名型、回归 xxx 型（如回归运动）、品牌自上而下重塑型；按范式：行业/赛道需求起来、转投大哥、大哥倒了小弟吃饱 |
| 公司成长 | 国牌改革（品牌周期）；低基数非线性；品牌升级；全球化故事支撑高估值 |

两类叠加时用"+"连接，例如"困境反转，回归运动型 + 行业整体需求 Beta"。

**五维度表**：管理层、战略、产品、客群、渠道 × 最近 3 个季度，逐格根据当季业绩会 transcript 填写。所有公司都要写，包括 set-up 一般的公司——它是后续跟踪的底稿。

### 第 7 步：写入 Obsidian

把结果按 `output-template.md` 的结构存成 `<TICKER>.json`，然后：

```bash
python scripts/render_obsidian.py --vault <vault 路径> <TICKER>.json [更多 json ...]
```

脚本写入 `<vault>/机会扫描/<TICKER>.md`（覆盖正文、保留并追加"历史扫描记录"），并根据所有笔记的 frontmatter 重建 `summary.md`（按机会大小排序）。批量扫描时，所有公司处理完再统一渲染一次即可。

扫描结束后，在对话里简要汇报：扫了几家，大/中/小各有哪些，每个"大"和"中"一句话说明为什么。

### 第 8 步：填写公司跟踪表

**自动触发**：扫描每家公司时，检查该公司跟踪表是否已包含最新一个已出财报的季度。如果尚未填入，自动执行本步骤。等同于单独调用 `/update-table`。

读取 `references/table-filling-guide.md`，按规范为该公司填写或更新跟踪表（Excel）。

0. **拉取原始资料**：检查 `library/{TICKER}/earnings/` 和 `library/{TICKER}/filings/`，如最新季度的 Transcript 或 Filing 缺失，先通过 FMP API / `scripts/sec_edgar.py` 拉取并保存到对应位置。
1. **定位 Excel 和目标列**：打开 `library/{TICKER}/{TICKER} table.xlsx`，按 row 2–4 日期确定目标季度的列位置，不存在则新增。
2. **更新 Valuation Screening**：运行 `python3 scripts/valuation_update.py {DISPLAY_TICKER}`。
3. **收集数据并填入**：按 `table-filling-guide.md` 中每个 Section 的 Source 优先级，依次从 FMP historical prices、Valuation Screening、FMP financials、Transcript（本地）、Filing（本地）获取数据，按科目名称定位填入。Section 4 定性内容以 Transcript 为唯一来源，不可编造。
4. **格式**：列宽 80，所有格子 `wrap_text=True` + `vertical='center'`，数字格子 `horizontal='center'`，增速/利润率用 `0.0%`。
5. **保存**。

## 判断纪律

来自原始研究：

- **反转类：对"够烂"和估值要严格，对后续怎么改的要求相对宽松**，只要方向正确。赔率的根基是估值足够便宜，所以"不够差"的公司机会大小最多是小。
- **成长类：对"变化"的要求更高**，因为估值本来不便宜。高估值以高增速为前提，核心是跟踪增速。
- **Beta 很重要。** 2015–2020 年底部公司普遍反转成功，主要受益行业整体需求。最好的范式是"行业或细分赛道需求起来 + 公司处在底部且在做正确的事"。
- **品牌自上而下重塑需要多年**（ANF 2017→2023，Tapestry 2021→2024）。时间不确定，但一旦改好不会是小机会。
- **右侧确认往往不晚。** 底部公司一旦收入势能被业绩确认，估值从"挣扎的公司"切换到"成长的公司"，EPS 对收入高度敏感，股价反应会很大。
- **数字以 Masterfile 为准**，叙述以原始研究为准；数据有已知异常（见 `data-guide.md`），遇到极端值先核对。

## 示例（历史回放，校准写法）

站在 2022 年 7 月看 ANF：

- **门槛**：Forward 净利率 2.2%、PS 0.24x（约 10% 分位），CEO 自 2017 年推动品牌重塑、门店从 330 家关到 220 家 → 过困境反转门槛。
- **匹配**：定量最近的是 VSCO 24Q2、GAP 23Q3（都是假反转）、CROX 17Q2、GAP 20Q1——数字本身分不出真假反转。定性上 ANF 是系统性的品牌与客群重塑，选 CROX 2017 年起的反转作类比。
- **大小**：足够差，且管理层、产品、客群、渠道已多年同向改变；财务上的早期信号（收入加速、毛利率同比改善）出现前记为"中"，出现后升为"大"。

结论段（方括号处在实际使用时依据 transcript 填写）：

> 目前 ANF 的 set-up 是"底部反转候选、品牌重塑已进行多年但尚未反映到收入"：最近 3 个季度，[如：客群继续向 25–35 岁职场人群迁移、门店从净关闭转向企稳等最重要的变化]。如果未来收入增速明显加速、同时毛利率同比大幅改善，和 2017–2019 年的 CROX 很像（反转后净利率从约 0 修复到 7%，PS 0.5x → 1.7x），是一个"困境反转，品牌自上而下重塑型"的机会。
