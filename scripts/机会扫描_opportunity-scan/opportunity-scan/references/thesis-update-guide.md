# Thesis 更新方法论

每当公司发布新一季财报后，更新该公司的 thesis。Thesis 更新不是重写——是在已有判断的基础上，用新季度信息验证/修正/补充，并重新评估机会。

## 核心原则

1. **Thesis 是活文档**——每次业绩更新都是一次迭代，不是从零开始。
2. **论断追踪是增量**——对上一版 thesis 的每个核心判断逐条做"证实/强化/减弱/维持"评价，体现动态演变。
3. **投资机会判断是全局**——不是只看最新一个季度，而是综合所有已有信息重新过一遍机会扫描框架。
4. **数据从 table 来**——table 已经是 transcript + filing 的结构化提取，不需要重读原始 transcript。
5. **新建文件，不覆盖旧版**——文件名带日期，旧版保留作历史记录。

## 数据来源

| 数据 | 来源 |
|------|------|
| 季度财务、业务拆分、定性内容 | `library/{TICKER}/{TICKER} table.xlsx`（最近 5 个季度） |
| Forward PE / PS / NPM / 一致预期 | `output/monitor/Valuation screening.xlsx` |
| 外部分析（sellside 等） | `library/{TICKER}/analysis/`（如存在） |
| 机会类型定义与门槛 | `references/opportunity-types.md` |
| 历史案例与数字画像 | `references/benchmarks.md`、`references/case-library.md` |
| 定量匹配 | `scripts/match_setup.py`（过门槛时使用） |

## 更新流程

### 第 1 步：读取旧 thesis，提取核心论断

打开 `library/{TICKER}/` 下最新的 `*thesis*.md`，逐段阅读，提取：

1. **上次的机会大小判断**及理由
2. **核心论断清单**（3-6 条）——从"小结"和"投资机会判断"中识别，每条是一个可被后续数据验证或推翻的命题
3. **"如果未来…"条件**——上次标注的观察条件
4. **上次的估值快照**——Forward PE / PS / NPM / 股价 / 一致预期 EPS

### 第 2 步：从 table 和 Valuation Screening 获取新数据

从刚更新的 table 中读取最近 5 个季度，重点关注：

- 收入趋势（各地区、渠道、品类的增速变化方向）
- 利润率趋势（GM、OPM、NPM 环比和同比）
- 关键经营指标变化（库存、折扣、门店等）
- 管理层指引的变化（比上季更乐观还是更悲观）
- Section 4 定性内容中的战略/产品/渠道新动向

从 Valuation Screening 读取：
- 最新 Forward PE / PS / NPM
- 一致预期 EPS 和收入（与上次对比）

检查 `library/{TICKER}/analysis/` 是否存在：
- 如有，读取其中的 sellside 报告或其他外部分析
- **重点关注**：市场/股价的核心 debate 是什么——这些分析通常结合股价变化去解读市场在意什么，这比卖方自身的观点更有价值
- 用途：写小结时作为参考，防止抓错重点（比如市场可能最关注的是 wholesale 放缓而非 DTC 增速）；投资机会判断部分适当结合，但核心仍依据机会扫描框架

### 第 3 步：论断追踪

对第 1 步提取的每条论断，给出判断：

| 判断 | 定义 |
|------|------|
| **证实** | 此前是假设或情景，现在有硬数据确认 |
| **强化** | 判断方向不变，新证据使确信度提高 |
| **减弱** | 出现方向相反的证据 |
| **维持** | 无新的实质性证据，趋势不变 |

另外标注**新增**——旧 thesis 未涉及但本轮出现的重要新变量。

格式要求：**分点写，每条简洁**——论断 + 判断 + 一句话依据。不要写成密集段落。示例：

```
1. **Running 20%+ 增长是 sport offense 有效性的核心证据** → **维持**
   连续 5+ 季双位数增长。已从假设变为 established fact，不再是核心矛盾。

2. **Greater China 持续恶化，需要全面重置** → **强化**
   从 -10%（Q3）恶化到 -17%（Q4）、-26%（Q1）。CFO 明确 FY27 剩余时间将进一步恶化。

3. **市场已 price in 恢复预期（21x PE / 5.5% NPM）** → **减弱**
   FY27E EPS 从 $1.66 砍至 $1.28（-23%），市场并未 price in 恢复——在下修。但股价仅跌 3%，PE 升至 27x，说明给长期修复留了信用。

新增变量：
- Pace 计划 $2.5B 节省（FY29-30 兑现）——首次给出具体利润率修复路径
- CFO 换人（Dave Denton），FY27 adj EPS 指引 $1.15-1.35，大幅低于前任含糊引导
```

### 第 4 步：重新过机会扫描框架

用更新后的数字重新走一遍机会扫描 SKILL.md 的第 3-5 步逻辑。

**4a. 门槛判断。** 读 `opportunity-types.md`，用最新 Forward NPM / PS / PE 检查各类门槛：

| 类型 | 关键门槛 |
|------|----------|
| 困境反转 | Forward NPM < ~3%？PS 在 10 年低位？有实质变化动作？ |
| 公司成长 | 各子类门槛（低基数、品牌升级、国牌改革、全球化） |
| 行业 Beta | 是否有新的 Beta 启动或消退？ |

**4b. 如过门槛。** 跑 `match_setup.py` 看定量匹配，与上次对比：类型是否变了？最像的案例是否变了？

**4c. 与上次对比。** set-up 更接近还是更远离门槛？关键关注：
- Forward NPM 下降 → 对困境反转类更有利（更接近"够差"门槛）
- Forward PS 下降 → 估值安全边际增大
- 基本面变化的系统性和持续性是否增强

### 第 5 步：写更新后的 thesis

文件命名：`library/{TICKER}/{TICKER}_thesis_{YYYY-MM-DD}.md`，不覆盖旧版。

结构与旧版一致，逐 section 更新：

**一、基本面**
- **最新指引**（第一个 section）：对比上季引导，逐项标注 上调/下调/维持。核心指标包括收入、EBIT/利润率、EPS、SG&A 等管理层给出引导的项目。用表格呈现：上季引导 | 本季引导 | 变化。附一句话说明下调/上调的核心原因。
- 年度财务：如跨新财年则追加一列
- 业务拆分：同上 5 个季度
- 关键经营数据：同上；如有新的重要 KPI 新增行
- 当前估值：更新到当天，增加上次数值作对比
- 小结：重写，覆盖 5 个季度视角，突出与上次的关键变化

**二、投资机会判断**

结论段：综合所有季度信息重新审视，不是只看最新一季。语言自然，像研究员的分析笔记。结构：
1. 当前 set-up 的核心描述
2. 关键变化的分析（哪些在变好/变差、净效应）
3. 与门槛的距离
4. "如果未来…"的更新版可观测条件

论断追踪：第 3 步的输出，**放在结论段之后、机会大小之前**。

机会大小：判断（大/中/小/—）+ 方向性变化。格式：

```
**机会大小：—（vs 上次 —）**。[理由]。

**变化：[方向描述]**。[一句话原因]。
```

方向描述用自然语言，如"机会略增大，Forward NPM 下降使其更接近困境反转门槛""set-up 无实质变化""恶化，估值因分母缩小变贵"。

五维度表：滚动到 5 个季度。

**历史扫描记录**：追加一行，保留所有旧记录。

**外部观点**（新增 section，放在历史扫描记录之前）：
- 检查 `library/{TICKER}/analysis/` 下的文件数量
- 如果 ≥ 3 篇，新增 "### 外部观点" section，归纳整理各篇的观点和论据
- 每篇一段话，格式：先标注评级（如 Buy / Sell / Hold / Strong Buy），再精简概括核心观点和依据
- 这是参考信息，不影响我们自己的机会大小判断

### 第 6 步：同步到 Obsidian

如 Obsidian vault 中有 `机会扫描/{TICKER}.md`，用 `render_obsidian.py` 更新；如无则跳过。

## 写作风格

- 结论先行，数据支撑——不堆数字，用数字说明判断
- 语言自然，有分析深度但不啰嗦，不要模板化套话
- 区分事实（直接陈述）与观点（"我们认为"）
- 标注来源：`[FY27Q1 Earnings Call]`、`[10-K]`、`[Valuation Screening 2026-10-12]`
- 论断追踪：干脆利落，每条一个判断，不要"可能强化"
